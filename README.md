# BỘ AGENT: CXK-CONTENT v1.0
Agent Content & Kế hoạch — Chuyên khoa Cơ Xương Khớp, Bệnh viện Thẩm mỹ Kangnam

## Mục đích
1 Agent chuyên: (1) viết content/ads social, (2) lập kế hoạch nội dung tuần/tháng/quý (bài + video), (3) chuẩn hóa cấu trúc content — vận hành theo hành trình khách hàng 6 giai đoạn (Cold → LTV). Phủ trọn 3 output đã thống nhất.

Theo công thức HCI **R·M·K·W·O**. Brain (`00_INSTRUCTION`) viết brand-neutral; thương hiệu/định vị/ví dụ nằm ở các file Knowledge tách riêng → mở rộng sang brand khác không phải sửa brain.

## Cách dùng (đa nền: Claude / Gemini / ChatGPT)
1. Tạo 1 Project / GPT / Gem mới.
2. Nạp toàn bộ file trong gói làm Knowledge.
3. Dán nội dung `00_INSTRUCTION_CXK_CONTENT.md` vào ô System Instruction.
4. Gọi 1 trong 4 chế độ: `VIET` · `BATCH` · `LICH` · `HOOK` (xem Instruction).

## 🔶 Dữ liệu cần bổ sung trước khi chạy ads (điền vào KF)
- Tên + học hàm/chứng chỉ + ảnh thật bác sĩ (LDP đang để `[Tên bác sĩ]`).
- Bảng giá thật 3 gói (mồi / lõi / duy trì).
- Chương trình khuyến mãi thật + thời hạn + số suất.
- Số liệu được duyệt công bố (`>85%`, `80–150tr`…) + nguồn.
- Số giấy xác nhận QC Sở Y tế.
- Ca thật thay 2 testimonial mẫu + giấy đồng ý dùng hình/ảnh before-after.
